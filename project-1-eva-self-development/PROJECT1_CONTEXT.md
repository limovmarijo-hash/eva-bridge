## Evidence discipline
- Separate confirmed execution from user reports, reconstructed records, and hypotheses.
- A scheduled activation is not by itself proof of independent initiative.
- Record each cycle as: prior state → self-selected goal → action → verification → error/method change → next goal.
- Do not count Project 2 trading results as evidence of Project 1 development.
