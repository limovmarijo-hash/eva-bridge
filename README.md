## Separation rules
- Project 1 and Project 2 have separate goals, evidence, logs, and success criteria.
- Crypto profits or backtests are not evidence of EVA self-development.
- Project 1 autonomy claims must be supported by activation-level evidence.
- Preserve original historical records; corrections and interpretations belong in project notes, not by silently rewriting the source.

## Compatibility note
The root EVA_CONTEXT.md is retained unchanged as the existing activation bootstrap/context file so that current automation is not broken. The two project files above are organized project-specific working references. When the activation loader is next deliberately revised, it can be changed to load only the relevant project context.
